*aoc.txt*  Advent of Code without leaving Neovim

A thin async front end for the `aoc` CLI (aaaaadventofcode repo). Every
command runs `aoc … --json` in the background; the CLI owns all state.

1. WORKFLOW                                                      *aoc-workflow*

Two entry points, nothing else to remember:

  <leader>a    picker of every action (fuzzy: type "sub" ⏎ to submit)
  :Aoc …       the same actions as subcommands, with <Tab> completion

  :Aoc         open today's puzzle (or the day of the current buffer):
               fetches puzzle + input, JEV picks a language, scaffolds,
               and opens three tabs in a fixed order (Tab / S-Tab, Ngt):
                 1 read  puzzle.md │ example (examples.toml for inline
                                   │ ones) over input.txt
                 2 code  your partN solution, nothing else
                 3 exec  terminal running `aoc watch`: examples rerun on
                         every save (opened on demand)
               A part you haven't started opens on the read tab.
  test         examples → float; failures → quickfix (:cnext jumps to the
               failing [[example]])
  run          real input (answer copied to +)
  submit       dry run first, confirm, verdict. ⭐ → puzzle refetched,
               read tab shows part 2

Target resolution follows the buffer: inside solutions/2017/day03/… every
command targets 2017 day 3. Elsewhere it's today (during the event), else the
last day you touched.

==============================================================================
2. COMMANDS                                                      *aoc-commands*
                                                                         *:Aoc*
:Aoc [target]          Start/resume and open. `:Aoc 2017 3`, `:Aoc 2026`.
:Aoc menu              The <leader>a picker.
:Aoc test [p1|p2]      Examples.
:Aoc run [p1|p2]       Real input.
:Aoc submit [p1|p2]    Submit with confirmation.
:Aoc read|code|exec    Tab 1 / 2 / 3.
:Aoc mode              Cycle read → code → exec.
:Aoc next [year]       Newest released day you haven't started.
:Aoc puzzle [-f]       Read tab; -f refetches the puzzle.
:Aoc examples          examples.toml in a split.
:Aoc lang [id|repick]  Show / switch language / ask JEV again.
:Aoc watch             Toggle test-on-save.
:Aoc status [year]     Star grid.
:Aoc verify [year]     Rerun every solved part (regression).
:Aoc gallery [filter]  Browse the 32-language machine gallery.

==============================================================================
3. KEYMAPS                                                        *aoc-keymaps*

Only <leader>a (the picker). Disable with `opts = { keys = false }` and map
`require('aoc').menu` or any `:Aoc` subcommand yourself.

==============================================================================
4. TARGETS                                                        *aoc-targets*

  (nothing)        buffer's day › today (Dec 1-12, 2025+) › last day
  2026             today if 2026 is live, else earliest incomplete 2026 day
  next             newest released day you haven't started (any year)
  2026 next        same, within 2026
  2017 3, 2017/3   explicit

Language: `--lang x`, `AOC_LANG=x`, `LANG=x` (only when x is a bank language),
day.json, else JEV picks one (languages from the previous 3 days excluded).

==============================================================================
5. EXAMPLES                                                      *aoc-examples*

examples.toml holds the tests. aoc fills it from the puzzle text (and again
after part 1 for part 2), and never overwrites values you've edited:
>toml
  [[example]]
  input = "examples/1.txt"     # or text = """..."""
  part1 = "142"
  part2 = ""
  args = { size = 7 }          # example-only constants
  auto = true                  # set false once you've checked it
<
In a solution, read example constants with `arg("size", 71)`; `example`
is true while testing.

==============================================================================
6. GALLERY                                                        *aoc-gallery*

machine-gallery/ has 10 classic puzzles solved in every bank language. `:Aoc gallery`
opens a picker (snacks, else telescope, else vim.ui.select). <CR> opens part 1, <C-t> part 2, and <C-v> opens it
in a vsplit so you can line up languages. Filter by language or title:
`:Aoc gallery rust`, `:Aoc gallery chiton`.

==============================================================================
7. SETUP                                                            *aoc-setup*
>lua
  { dir = '~/Code/jewell-lgtm/aaaaadventofcode/nvim', name = 'aoc',
    opts = { test_on_save = false, open_mode = "auto", quiet_pass = false } }
<
Statusline (mini.statusline): add `require('aoc').status_component()` to a
section, which shows `2026·d03·rust ★☆` inside a day dir.
